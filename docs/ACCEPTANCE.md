# SourcePin 10 分钟人工验收

开始前运行：

```bash
npm ci
npx playwright install chromium
npm run build
npm run dev
```

在 Chrome 打开 <http://127.0.0.1:4317>。若要验收扩展能力，再到 `chrome://extensions` 开启开发者模式，加载 `dist/extension`。

## 1. 书签安装、唤起与退出（1 分钟）

打开 <http://127.0.0.1:4317/dist/site/index.html>，将 SourcePin 标签拖到 Chrome 书签栏。然后打开验收页，点击刚保存的书签。也可在安装页点“唤起 SourcePin”先体验。

预期：右下角只出现一个绿色掌机；首次引导显示 Lite、中文、手动录制默认值。点击“开始选择”后引导立即关闭。首次 Esc 清空选择并关闭面板，第二次 Esc 退出；再次唤起不会叠加第二个掌机。

## 2. 单选、复制与预览（1 分钟）

重新唤起，点击“工作空间”卡片，先不要按复制键。随后按 `Cmd/Ctrl+C`，再双击掌机屏幕。

预期：点击只选中并高亮卡片，不执行卡片内按钮，也不自动写剪贴板。捕获完成后屏幕显示数量，短内容会显示摘要及定位状态，长内容保留笑脸；复制成功后红色圆钮变绿，剪贴板得到 Markdown；预览中可滚动查看完整输出。聚焦屏幕后按 Enter 也能打开预览。

## 3. 多选与定位更新（1 分钟）

关闭预览，普通点击“工作空间”卡片，再按住 Shift 点击“灵感正在生长”卡片。随后按两次 Esc 退出 SourcePin，点击页面的“重排列表”，再唤起 SourcePin 并重新选择变化后的列表项。

预期：退出前两个选择框同时存在。重新选择变化后的列表项会更新 HTML、CSS 和定位快照。导出内容反映重新选择时的页面状态，而不是持续同步的源码。

## 4. 原生复制保护（1 分钟）

按两次 Esc 退出工具，展开“更多验收场景”，再唤起 SourcePin。在输入框或可编辑文字中选择文本并按 `Cmd/Ctrl+C`。

预期：网页原生复制保持可用，SourcePin 不覆盖输入控件或网页文字选区的复制。普通线上页面若没有开发元数据，输出明确表示源码文件和行号不可得。

## 5. Lite / Pro 与录制（2 分钟）

点掌机下方的 Switch 切换到 Pro，选择“查看项目”按钮；打开蓝色设置面板，开始录制。正常把鼠标移入、聚焦并点击该按钮，再停止录制。

预期：掌机变为红色主题，选中内容重新按 Pro 采集。录制期间原网页交互正常执行，停止后预览或导出包含实际观察到的状态和迁移。停止录制后不会自动恢复拾取；按一次 Esc，或打开设置并点“重新选择元素”后，可以选择下一目标。

## 6. 截图与多视口（1 分钟，仅扩展版）

保持目标标签页在前台，点三角按钮，分别尝试“截取组件”和“截取当前视口”。手动缩窄浏览器窗口，再点“追加当前视口”。

预期：下载 PNG，截图中没有 SourcePin 掌机；组件截图只裁剪目标当前可见部分，视口截图只记录当前可见画面。追加视口记录手动调整后的尺寸，不会替你改变窗口。书签版会说明截图需要 Chrome 扩展。

## 7. 下载（1 分钟）

点击黄色 M，或尝试 `Cmd/Ctrl+Shift+M`。

预期：浏览器请求可选下载权限或发起普通下载，得到可打开的 `.md` 文件。快捷键若被浏览器占用，可在 `chrome://extensions/shortcuts` 修改；黄色 M 始终可用。取消保存不应显示已经保存成功。

## 8. 隐私与书签版边界（2 分钟）

选择“更多验收场景”中的隐私字段区域并导出，搜索测试密码、token、脚本和事件属性；再把页面底部 SourcePin 链接拖到书签栏，在普通网页尝试书签版。

预期：DOM Markdown 不包含表单值、敏感 token、脚本或事件处理属性；截图中的可见文字仍属于原始像素，没有脱敏。书签版可完成共享内核的选择、复制和 Markdown 下载，但没有扩展截图及 Chrome 设置同步；严格 CSP 页面可能阻止运行。

验收发现的问题请记录使用方式、页面 URL、Chrome 版本、操作步骤、预期和实际结果，并附上相关 Markdown 或截图。GitHub 发布账号、目标仓库和许可证在本轮验收完成后再确定。


## 本轮视觉核对

- Lite / Pro 机身和底部 Switch 颜色同步，机身阴影只沿右下轮廓出现，没有矩形背景。
- 可见的圆形按钮、M、三角与齿轮在按下时收缩，松开后回弹；系统减少动态效果设置下停用。
- Switch 常驻机身下方居中，轨道 44×22，拇指15，视觉轨道描边2.5、拇指描边2、标签9 px。
- 选中组件并打开面板后，第一次 Esc 清空选择、关闭面板但掌机保留；再选组件再按 Esc 仍只取消，下一次 Esc 才退出。
