# SourcePin

SourcePin 是一个本地运行的网页元素采集工具。点击网页组件后，它会生成可交给 AI 的定位、结构和样式上下文。Lite 适合定位，Pro 会采集更完整的结构和样式信息和用户实际触发的交互状态。无需账号，采集结果不会上传。

## 下载当前可用版本

当前源码托管在公开仓库 [N107meow/SourcePin](https://github.com/N107meow/SourcePin)，许可证为 [MIT](LICENSE)。打开 [v0.1.6 下载页](https://github.com/N107meow/SourcePin/releases/tag/v0.1.6)，下载 `sourcepin-0.1.6-delivery.zip` 并解压（包内顶层是 `sourcepin-0.1.6/` 目录），用 Chrome 打开其中的 `install.html`，将 SourcePin 标签拖到书签栏即可使用；扩展用户可加载包内的 `extension/`。

也可以直接使用仓库的 GitHub Pages 安装页（见下）；GitHub 自动生成的 Source code 压缩包用于开发，不包含构建产物。

## 更新记录

用户可感知的功能变化见 [GitHub Releases](https://github.com/N107meow/SourcePin/releases)（每个版本的发布说明即更新记录）。版本号与 git 标记一致。

## 安装到浏览器书签栏（主要方式）

1. 打开 SourcePin 安装页：<https://n107meow.github.io/SourcePin/>（本地开发时为 <http://127.0.0.1:4317/dist/site/index.html>）。
2. 显示浏览器书签栏，将页面上的 **SourcePin** 标签拖进去。
3. 打开要采集的普通网页，点击书签栏里的 SourcePin，即可唤起游戏机。

无需用户安装 Node.js、启动本地服务或加载 Chrome 扩展。书签包含完整工具代码；更新版本时从安装页重新拖入并替换旧书签。不能拖拽时，安装页提供手动创建书签的完整代码。

GitHub 的仓库 README 会净化可执行链接，因此采用“仓库首页 → GitHub Pages 安装页 → 拖进书签栏”的路线。[GitHub Markup 说明](https://github.com/github/markup)、[GitHub Pages 说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

线上拖拽安装页由同仓库的 GitHub Pages 承载；离线安装包见上方版本下载页。Pages 的部署步骤与回退方式见 [GitHub 分发说明](docs/PUBLISHING.md)。

## Chrome 扩展（可选增强版）

项目已经提供 `dist/sourcepin-0.1.6-chrome.zip` 和 `dist/extension`：

1. 解压 `dist/sourcepin-0.1.6-chrome.zip`；也可以直接使用交付目录中的 `dist/extension`。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的目录或 `dist/extension`。
4. 打开普通 HTTP/HTTPS 网页，点击 SourcePin 扩展图标，或按 `Cmd/Ctrl+Shift+Y` 唤起。

如果快捷键与浏览器或其他扩展冲突，可在 `chrome://extensions/shortcuts` 修改。下载快捷键是 `Cmd/Ctrl+Shift+M`，但该组合可能被浏览器保留；游戏机上的黄色 M 按钮是可靠入口。

## 使用

书签图标：安装页上的 SourcePin 标签自带方形图标，扩展版的工具栏按钮和扩展管理页也用它。浏览器给书签栏显示哪个图标由浏览器自己决定：`javascript:` 书签没有可抓取的站点图标，SourcePin 不去改运行页面的图标，也不保证书签栏那一项显示方形图标。

**SourcePin 不改动你正在看的那个标签页。** 书签版和扩展版运行前后，页面的 `document.title`、`<head>` 里的全部内容（含 `<link rel="icon">`）和地址栏 URL 都保持逐字节相同：不重命名标签页、不替换 favicon、不动书签栏任何一项，也不运行任何加载期脚本。这条已经写成端到端回归（两个适配器各断言一次）；`artifacts/tab-identity-check.js` 是给用户自查用的监视脚本，粘贴进 Console 即可列出使用期间标题/head/图标的任何改动。

使用引导只在安装页首次点击“唤起 SourcePin”体验时显示；书签在目标网站唤起时直接进入拾取，不再反复弹出引导。安装页仅保存一个本地“已显示引导”标记，关闭、刷新、换页后仍有效；清除站点数据会重置，存储被禁用时只能在当前页面记住。扩展版把该标记保存在扩展本地设置中，跨网站也只显示一次。首次引导一出现就记为已显示，直接按 Esc 关闭也不会在下一次重复。

导出确认不属于使用引导，它跟着**一次已接受的选择**走。首次复制、下载或截图会显示完整确认（个人信息计数、LLM 第三方处理提示、权利声明）；接受之后显示一行小字「已确认 · 声明」，点击或按 Tab 聚焦后按 Enter 可随时重新打开完整声明（只读，不再询问），本次选择内的后续导出不再弹窗。

**取消不等于同意**：在确认框上点「取消」或按 Esc 只取消这一次导出，不写剪贴板、不下载、不留「已确认」小字；下次导出会重新显示完整确认。只有点「继续导出」才记录已确认，并且只对当时那一份快照有效——重新选择元素、换目标、页面结构变化或改模式后都重新确认，即使新快照本身干净。

这行小字只在选中或复制状态下显示：清空选择后屏幕回到只剩笑脸的状态，不会一直占着界面；悬停屏幕可读到完整告知。

免点击只针对干净内容：**只要快照里检测到个人信息计数大于 0，无论第几次、无论复制还是截图，都会重新显示完整确认**。复制、下载、截图三种导出共用同一次确认；截图可能含文字且未做 OCR，这条告知保留在首次弹窗的正文里，不随免点击消失。每次导出都会重新扫描当前内容，不会因为「已经同意过」而跳过检查。

- 指向元素查看高亮，点击选择；点击不会自动复制，也不会执行原网页操作。
- 按住 Shift 点击可多选，再按 `Cmd/Ctrl+C` 或游戏机红色圆钮复制摘要。
- 黄色 M 按钮下载完整内容（元素为 Markdown，整页为 ZIP）；单击屏幕或聚焦屏幕后按 Enter 可打开预览。预览窗为 188×264，与机身等大并位于其上方；较矮窗口会缩短预览高度，内容可在内部滚动。预览与复制使用同一份 15 KiB 有界摘要，下载始终是完整报告；即使整页全文超过 4 MiB，预览也会显示目标与定位信息，而不是报错。
- 单击粉色圆钮里的齿轮图形打开设置面板；单击左下角的绿色图标显示或隐藏机身下方的 Switch（默认隐藏），用 Switch 切换 Lite/Pro。三角按钮打开截图、整页 DOM 和追加视口操作。
- Pro 录制只记录你真实触发的 hover、focus、点击和页面变化。停止录制后，按一次 Esc 或在设置中点“重新选择元素”恢复拾取。
- 截图只包含当前可见视口；组件截图也只能裁剪目标当前可见的部分。追加不同视口前，需要手动调整浏览器窗口大小，再点“追加当前视口”。
- Esc 分层收起：有面板打开时只关闭该面板（确认框上按 Esc 即取消本次导出），已选组件与采集结果都保留；没有面板时按 Esc 取消选择，再按一次才退出。重新选择组件后重新计算，长按不会误触退出。
- 键盘可达：机身与面板的控件都有可见焦点（Tab / Shift+Tab 逐格移动），打开面板后焦点落在面板内，关闭后回到刚才那个按钮。拖动条聚焦后用方向键逐格移动机身，Home 键复位到右下角。拖动条本身只负责拖动，位置始终限制在视口内。
- 机身下方的 Switch 仅在点击绿色图标后出现，用来切换 Lite / Pro；`LITE` / `PRO` 字样跟着 Switch 一起出现和消失，关闭后机身下方不留文字。机身颜色只是辅助信号。
- 「截取组件」「截取当前视口」需要 Chrome 扩展版。书签版与安装页里这两个按钮为禁用态，并在面板内一行和 `title` 中说明原因。Lite 下「开始录制」会一步切到 Pro 并开始录制；「追加当前视口」在未选择元素时会明确提示。
- 最多同时选择 10 个组件；达到上限时再 Shift 点击会提示上限，而不是静默丢弃。Shift 多选提示随悬停标签出现一次并停留约 1.6 秒；指针移开即结束，开始新一次选择后可以再出现一次。

HTML 与 CSS 是选择时的快照。页面变化后应重新选择，以更新结构、样式和定位结果；复制或导出前工具会再次检查定位。普通线上网页通常没有源码文件和行号，只有页面提供 React/Vue 等开发元数据时才可能得到来源信息。

截图保存的是页面像素，其中可见文字没有脱敏。DOM 输出会过滤表单值、脚本、事件属性、敏感属性和 URL 参数（包括查询串、`#fragment` 中的 `access_token` 一类参数，以及 URL 里的用户名密码），伪元素通过 `content: attr(...)` 复读被过滤属性时整条声明会被省略，Pro 录制的变化详情也走同一套过滤，只保留原因和计数；但仍应在分享前检查内容。

## 设置面板

点击机身右下角的齿轮图形打开设置。修改后立即生效。

方形图标取用 Lite 状态的屏幕（青绿机身框、浅色屏面与笑脸），扩展工具栏按钮、扩展管理页与安装页标签页都用它。改动图标后运行 `node scripts/make-icons.mjs` 重新生成四个尺寸。

| 功能 | 用途 |
| --- | --- |
| 输出语言 | 切换中英文界面标签及报告说明；不翻译网页原文、代码或属性名。 |
| 最大节点数 | Pro 采集组件结构时的元素数量上限，默认 300，可设 20–1000；一次多选合计最多 600 个节点。Lite 的元素形态只采集目标本身；整页形态使用独立预算。 |
| 最大深度 | Pro 元素形态向子元素展开的层数，默认 6，可设 1–12；选中元素算第 0 层。节点数或深度任一到限就停止展开。 |
| 包含隐藏内容 | 默认关闭，排除 hidden、display:none、visibility:hidden/collapse 子树；开启后明确标记隐藏节点。对整页和元素形态都有效。 |
| 开始／停止录制 | 在 Pro 模式下选中元素后，记录你实际触发的悬停、聚焦、点击及页面状态变化；不是录屏。多选时录制第一个目标，停止后将结果写入预览及导出。 |
| 重新选择元素 | 清空本次选择与录制结果，恢复点击拾取；不会删除已经下载的文件。 |

## 整页 DOM（Lite / Pro 均可用）

三角按钮 →「捕获整页 DOM」→ 黄色 M → 确认后下载离线 ZIP。Lite 下也会输出 `Structure`、`Cleaned HTML` 和 `Scoped CSS`；此操作不改变当前 Lite / Pro 模式。复制仍是 15 KB 摘要，能力清单会说明摘要省略的 HTML/CSS，完整内容需下载；`Reference Impl` 指向包内页面。

- page 形态独立预算：默认 20,000 节点、40 层，节点快照 + HTML + CSS 共用 2 MiB UTF-8 字节上限。元数据和 Markdown 格式开销不包含在此上限内。
- 结构先预留标签和闭合标签，再分配文本空间；样式最多采样 120 个代表节点，并受独立样式字节上限限制。整页形态按净化后的 tag/class/id/style 与至多两级父身份合并为不透明签名，每个签名采样一个代表节点：同签名的节点共用 `.sp-s-N` 规则，因此覆盖广但属于代表近似——`:nth-child`、更远祖先、布局或状态不同的同签名节点可能不一致，已写入 Degradations。元素形态仍是逐节点采样，不合并签名。未采样的计算样式、CSSOM 上限、文本和结构截断都写进 Degradations。
- 保留净化后的内联样式、`sizes`、template 惰性内容和开放 Shadow DOM（声明式 template）。导出时 `srcset` 作为图片位置来源被记录后移除。不读取 iframe 内部内容，closed Shadow DOM 不可检查；能力清单明确列出这些边界。
- `Capabilities` 紧接 `Meta`，按每份采集列出九项能力及原因；混合采集只为真正具备内容的快照追加 HTML/CSS。原 Lite 八节保留名称与相对顺序。
- `Meta` 包含采集形态、documentHeight、documentElement/html 的实时 rect、图片总数及 complete 数，便于外部核对。complete 是浏览器加载终止状态，包含成功和失败，不等于图片成功加载。
- 扩展偏好仅保存到 `chrome.storage.local`；书签偏好仅在当前工具实例内保存。没有内容上传、遥测、云同步、批量 URL 抓取或访问控制绕过。

### 离线包与体积策略

解压 ZIP 后打开 `page.html`。文件包含 doctype、html/head、内联 scoped CSS 和指向净化后原 URL 的 base。**图片不下载也不内联**：每个图片位置放一个尺寸取自该位置快照矩形的可解码 SVG 占位（没有可用的采集尺寸时才退回 `width`/`height` 属性或 `px` 内联声明，百分比、`rem` 之类的单位不会被当成像素），`srcset` 会被移除（否则浏览器会按它去请求原站），原候选仍完整保存在 `structure.json`。因此离线页保留版面与图片位置，但显示的是占位而非像素，体积也不随图片大小增长。多份快照分别输出 `page-2.html` 等文件；`structure.json` 保存结构与审计，`assets.json` 列出被标记的图片位置（`mode: marked-not-fetched`），`report.md` 保留全部报告章节并链接实现参考。

- ZIP 使用不压缩的本地容器，总上限 16 MiB；单份 HTML 8 MiB、完整 Markdown 4 MiB。超限明确拒绝并提示缩小范围或减少视口，不静默省略文件。
- 导出过程不发起任何图片请求：图片位置只被标记。因此不存在 CORS、鉴权、重定向或图片体积预算失败的问题，离线页也不会因为图片而超过体积上限。
- 包内页面 CSP 阻止自动外联；不执行脚本、不保留 iframe 内容、导航和表单提交，不下载字体、音视频。图片以外的这些能力属于明确降级，不能将静态快照视为原网站的完整功能。
- 剪贴板摘要为 15 KiB，列出被舍弃的具体章节；节点深度、文本和属性摘要仍有各自声明的上限。
- CSSOM 对简单选择器建立候选索引，复杂选择器回退到既有采样集合；最多 2,000 条规则、每个采样节点 20 条匹配、每条 keyframes 8,000 字符、补充 CSS 32 KiB。相同样式对象复用、CSS 声明合并，内联 CSS 取「完整声明组」与「属性值共享」中更小的一种；声明式 shadow root 各自写入其所需的代表规则。整页一次采集内，同一节点的普通样式与 `::before`/`::after` 各缓存一次读取，缓存不跨采集保留。
- 每 500 个节点或 8 ms 主动让出执行。自身 opacity 与祖先 opacity 分开记录，祖先动画的透明状态不会单独把目标判成 `visible:false`。

固定验收页：[整页 DOM 场景](http://127.0.0.1:4317/demo/page-capture.html)。最新浏览器证据见 [测试报告](docs/TEST-REPORT.md)。

## 本地开发与验收

要求 Node.js 22 或更高版本。首次运行：

```bash
npm ci
npx playwright install chromium
npm run build
```

常用命令：

```bash
npm run dev       # http://127.0.0.1:4317
npm run check     # 类型检查、单元/浏览器测试、生产构建
npm run test:e2e  # 另一个终端执行；需先 build 并保持 dev 服务运行
npm run delivery  # 在 artifacts/sourcepin-<版本>/ 生成可直接分发的安装包
```

`npm run delivery` 以 `site/index.html` 为模板生成安装包里的 `install.html`（只替换内嵌书签、体验入口与插图，其余内容与线上安装页一致），并附带已解压扩展、书签源码与 `SHA256SUMS`。

打开 [本地验收页](http://127.0.0.1:4317) 可直接体验共享内核。书签版产物是 `dist/sourcepin.bookmarklet.txt`：它与扩展共用采集内核，但没有扩展截图和跨会话偏好保存，并且可能受目标页 CSP 限制。源码检出后须先构建生成 dist。

现行能力契约与逐条验收规格见 [docs/ACCEPTANCE-SPEC.md](docs/ACCEPTANCE-SPEC.md)，手工步骤见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)，实测数字见 [docs/TEST-REPORT.md](docs/TEST-REPORT.md)。源码与安装包托管于 N107meow/SourcePin，许可证为 MIT。
